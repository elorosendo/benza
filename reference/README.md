# Referências visuais

São exportações das pranchas do canvas de design. As imagens já apontam para `../assets/`.

- `SiteV1.html`: Noite (base Penumbra). Mega menu aberto, blocos de categoria, chips "Por corpo", faixas das linhas.
- `SiteV2.html`: Dia, loja primeiro. Hero dividido, índice tipográfico de categorias, cards das linhas, novidades.
- `SiteV3.html`: Expressiva (base Mata). Wordmark gigante com colagem, grade "Conheça (o seu) corpo", lista de linhas, Ask Benza.
- `Linhas.html`: prancha do sistema das 4 linhas (paletas, pôsteres, etiquetas).

Os arquivos usam o formato de componente do canvas (tags `<x-dc>`, `<helmet>` e um script `data-dc-script`). Abertos direto no navegador, renderizam quase igual ao canvas. Use-os como especificação de layout, cor e tipografia, não como código de produção: os estilos inline devem virar classes e componentes.
